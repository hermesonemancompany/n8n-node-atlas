# n8n Node Atlas

Detailed static documentation for n8n core nodes, engineering patterns, and 50 real-world workflow blueprints.

- Official package: `n8n-nodes-base@2.15.1`
- Core node entries: 438
- Working examples: 50
- Responsive desktop/mobile docs shell
- Hierarchy-driven sidebar
- Documentation / Working examples tabs
- Editor-style n8n node visuals
- Light / dark / system mode toggle

## Scope

The node catalog is generated from the official core package manifest at build time. Community nodes and version-specific operation parameters are not represented as core coverage.
